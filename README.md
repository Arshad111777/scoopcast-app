# Scoopcast – Headless WordPress Mobile App

A modern cross-platform mobile application that delivers movie/entertainment media and updates. Built with React Native (Expo), leveraging WordPress as a Headless CMS for content management and TMDB API for live media feeds.

## 🚀 Key Features
- **Headless CMS Architecture:** Consumes content dynamically via WordPress REST API.
- **TMDB API Integration:** Fetches real-time movie data, trailers, posters, and details.
- **Optimized Performance:** Implemented persistent caching, background sync, and offline support with React Query and AsyncStorage.
- **Cross-Platform:** Seamless UI and performance across Android & iOS.

## 🛠️ Tech Stack
- **Framework:** React Native, Expo
- **State & Data Management:** React Query (TanStack Query), AsyncStorage
- **Backend/APIs:** WordPress REST API, TMDB API
- **Styling/UI:** Modern responsive mobile components
